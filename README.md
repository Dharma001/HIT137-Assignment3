# Spot The Difference Game

## Project Description

This project is a desktop application developed in Python that demonstrates object-oriented programming principles, graphical user interface development using Tkinter, and image processing using OpenCV. The application presents two images side by side where users must identify differences in the modified image.

## Key Features
- Load and display images in JPG, PNG, BMP formats
- Five randomly generated differences per image
- Three difficulty levels (Easy, Medium, Hard)
- Image processing using OpenCV (blur, brightness, color shift, pixelation, noise)
- Score and mistake tracking system
- Click detection with tolerance handling
- Reveal functionality for all differences
- Game completion and failure conditions

## Technologies Used
- Python
- Tkinter (GUI development)
- OpenCV (image processing)
- Pillow (image handling)

## Installation
```bash
pip install opencv-python pillow
```
